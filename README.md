Gamble

I  built an game where you have a menu, go move up and down to 3 different games, number guessing, high low card guessing game, and poker. In poker, you can play a bot that will do 5 - hand poker against you. In number guessing, you have 10 attempts to guess a number from 1 - 500. You get hints of how close you are. In the highlowcardbettinggame, you have 1000 coins and then you have to guess whether the next card will be higher or lower. There is a menu that displays how likely it is to be higher/lower, the percentage of the chance of being higher/lower, and the payout. After every round in all of the games, you go back to the menu to choose another game, or you can play the same game. If you choose to exit, the game stop and to play again, you have to run the code again.
